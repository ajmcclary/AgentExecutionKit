# AgentExecutionKit

Use Swift 6 with strict concurrency and a macOS 27 floor. Run `swift build` and
`swift test`; keep products separately buildable. No app or UI imports.

Inject host identity, environment, configuration, credential access, policy,
logging, storage, and MCP services. Never implicitly read app singletons,
Bundle.main, UserDefaults.standard, or the process environment.

ProcessKit owns process primitives; this package owns agent execution policy
and adapters. Keep provider vocabulary in its existing runtime kits. Preserve
provider-specific admission, recovery, cancellation, and accounting contracts.

CI is generated by the CodeEditor superproject's Scripts/sync-package-ci.
